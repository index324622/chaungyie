# 部署说明（从本机到公网）

本项目是**零第三方依赖**的 Node.js 应用，只需 Node ≥ 18 即可运行；`website/` 目录即完整应用，`website/deploy/` 提供了容器与代理配置。

> ⚠️ 当前工作机所在的沙箱**没有外网**（DNS 被指向 127.0.0.1、443 端口不可达、无代理），所以无法在本机直接创建公网隧道或拉取镜像。以下三种方式任选一种，在**有公网/有账号的环境**执行即可。

---

## 方案 A：云服务器 + Docker（推荐，可长期使用）

适合：阿里云/腾讯云/华为云轻量应用服务器（2 核 2G 起），有公网 IP；如有域名可自动 HTTPS。

### 1. 准备服务器
1. 购买轻量服务器（Ubuntu 22.04 / Debian 12），记下公网 IP。
2. 安全组/防火墙放行：`22`（SSH）、`80`、`443`；调试期可临时放行 `8788`。
3. 安装 Docker：
   ```bash
   curl -fsSL https://get.docker.com | sh
   systemctl enable --now docker
   ```

### 2. 上传并启动
把 `大学生兼职众包平台_部署包.zip` 上传到服务器（或用 `scp`）：
```bash
scp 大学生兼职众包平台_部署包.zip root@服务器IP:/opt/
cd /opt && unzip 大学生兼职众包平台_部署包.zip -d jianzhi
cd jianzhi/website
docker compose up -d --build
```
访问 `http://服务器IP:8788` 验证。

> `docker-compose.yml` 已把 `./data` 挂载到容器 `/app/data`，数据（订单、图片）在重启/升级后保留。

### 3. 绑定域名 + HTTPS（可选但强烈建议，定位功能需要 HTTPS）
1. 域名 A 记录解析到服务器公网 IP。
2. 在 `website/` 目录把 `deploy/Caddyfile.example` 复制为 `Caddyfile`，把 `example.com` 改成你的域名。
3. 取消 `docker-compose.yml` 中 `caddy` 服务与文件末尾 `volumes` 的注释。
4. 重新执行：
   ```bash
   docker compose up -d
   ```
   Caddy 会自动申请并续期 Let's Encrypt 证书，之后访问 `https://你的域名`。

### 4. 不用 Docker 的等价做法
```bash
cd website
HOST=0.0.0.0 PORT=8788 node server.js     # 可用 systemd/pm2 常驻
```
再用 `deploy/nginx.conf` 做 80/443 反向代理，`certbot` 申请证书。

## 方案 B：免费 PaaS（Render / Railway，几分钟上线）

> 仓库已准备好：项目根目录的 `deploy-repo/` 已 `git init` 并完成首次提交，根目录含 `render.yaml`，按 `deploy-repo/README.md` 的 3 条命令推送到 GitHub，再在 Render 里 New → Blueprint → Apply 即可。


适合：不想买服务器、能接受免费实例休眠与数据不持久。

1. 把 `website/` 推到 GitHub 仓库（建议用私人仓库）。
2. 打开 [Render](https://render.com) → New → Web Service → 选择该仓库。
3. 配置：
   - Root Directory：`website`
   - Runtime：Node
   - Build Command：`npm install --omit=dev`
   - Start Command：`node server.js`
   - 环境变量：`HOST=0.0.0.0`（平台会自动注入 `PORT`）
4. Create Web Service，等到状态 Live，得到 `https://xxx.onrender.com` 公网地址。

> 免费实例：15 分钟无访问会休眠（首次访问需等待几十秒）；文件系统是临时的，**重启后演示数据会重置**。需要保留数据就升级付费并挂载 Disk（挂载到 `/opt/render/project/src/data`），或用数据库替换 JSON 存储。
> `deploy/render.yaml` 是 Blueprint 配置，可一键导入。

## 方案 C：临时公网隧道（最快，适合答辩/演示几小时）

适合：本机有公网、不想买服务器；地址临时，关掉就失效。

### Cloudflare Tunnel（免账号，临时域名）
在有外网的机器上：
```bash
cd website
HOST=127.0.0.1 PORT=8788 node server.js     # 先启动应用
# 另开一个终端：
cloudflared tunnel --url http://127.0.0.1:8788
```
命令会输出形如 `https://xxx-yyy.trycloudflare.com` 的公网地址，直接发给他人在线访问。关闭进程即失效。Windows 可下载 `cloudflared.exe` 后执行同样命令。

### ngrok（需免费账号取 authtoken）
```bash
ngrok config add-authtoken <你的token>
ngrok http 8788
```
得到 `https://xxxx.ngrok-free.app`。

> 隧道同样支持 HTTPS，且**定位功能可用**（浏览器要求 HTTPS 或 localhost 才能读取 GPS）。

## 方案 D：只在教室/宿舍局域网演示（不需要公网）

Windows 双击 `deploy/start-lan.bat`（或命令行 `set HOST=0.0.0.0 && node server.js`），然后：
1. `ipconfig` 查看本机 IPv4（如 `192.168.1.23`）；
2. 同一 Wi-Fi 下手机/电脑访问 `http://192.168.1.23:8788`；
3. 如果其他设备打不开，检查 Windows 防火墙是否放行 Node.js（专用网络入站）。

> 注意：`http://` 页面在手机浏览器上默认不能读取 GPS，定位打卡会走"仅照片"分支；需要用 HTTPS 才能授权定位。

## 上线前安全清单

1. **改掉演示账号密码**：`website/data/db.json` 中 `users[*].password` 为明文演示密码，上线前必须改为哈希并加登录限流（可用 `/api/login` 前加验证码/次数限制）。
2. **不要放真实身份证、学籍、银行卡照片**：演示数据与上传目录仅供教学。
3. **必须启用 HTTPS**：涉及定位、上传、登录令牌。
4. **数据备份**：定期备份 `data/`（`db.json` + `uploads/`），或迁移到 MySQL/对象存储。
5. **限制上传**：当前限制 3MB/张、PNG/JPG/WebP；生产建议加图片鉴黄与访问签名。
6. **隐私合规**：个人信息最小化采集、单独同意、留存期限与删除入口（本原型仅作演示）。
7. **别用 `node server.js` 直接暴露在公网**：用 Nginx/Caddy 做反向代理，隐藏端口并启用限流。

# 局域网
cd website && HOST=0.0.0.0 PORT=8788 node server.js

docker compose up -d --build
docker compose logs -f

# 容器数据位置
website/data/          → 容器内 /app/data
