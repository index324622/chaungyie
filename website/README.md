# 大学生兼职众包平台 · 可运行网站原型（v4）

根据《大学生兼职众包平台案例分析》中的业务模型实现的本地可运行原型，用于课程演示、答辩展示或作为课程设计起点。**零第三方依赖**，只需要 Node.js（≥ 16）。

v3 在 v2（认证、通知、图片留痕、争议仲裁、看板图表）基础上补充了**电话与地图细节**：

- **真实地图找活**：接入 **Leaflet + OpenStreetMap**（免 Key，CDN 加载），任务按坐标打点、点击弹出详情；支持 **GPS 定位到我的当前位置**（反查地址显示在页面上）、在地图上点选位置、按 1/3/5/10 公里筛选、距离排序；每个任务附「高德地图」导航链接。CDN 不可用时自动退化为自绘示意图。
- **定位打卡**：打卡时读取浏览器 GPS，与任务坐标做 Haversine 距离校验：超过 5 公里禁止打卡，超过 800 米标记「定位异常」并通知运营；照片 + 坐标 + 距离一并留痕。
- **电话与隐私号**：学生报名后可「联系企业」，平台生成稳定的**虚拟隐私号**（170 号段 + 分机），一键拨打；企业真实电话脱敏展示；每次查看记录联系日志，运营可看到联系次数。
- **安全中心**：独立页面汇总 110 / 12333 / 96110 / 12315 / 12348 / 平台客服一键拨打，附兼职防坑清单与维权流程。

## 功能一览

### 学生端（`student.html`）
- **任务大厅**：类目 / 关键词筛选，按最新、报酬、热度、**距离最近**排序；卡片显示距你多远。
- **地图找活**：切换「列表 / 地图」，示意图上按类别打点，标记可点开详情；「我的位置」可选学校地标或使用 GPS 定位。
- **报名与联系**：实名 + 学籍校验、防重复报名；报名后可在任务详情「联系企业」，获取**平台隐私号**一键拨打，并查看高德地图导航。
- **自助认证**：填写学校、学号 → 运营审核（待认证 / 审核中 / 已通过 / 已驳回）。
- **我的订单**：打卡（自动读取定位 + 可传现场照片，显示距任务地点距离与是否异常）→ 提交成果（文字 + 最多 3 张附件）→ 验收 → 到账；可申诉、可评价。
- **我的钱包**：余额、累计收入、信用分、提现、收入明细（平台服务费 10% / 实得 90%）。
- **消息中心**：右上角铃铛 + 未读红点，10+ 类事件通知，支持全部已读。

### 企业端（`enterprise.html`）
- **发布任务**：增加「地图位置」选项（五一广场 / 湖大 / 中南 / 师大 / 会展中心 / 线上），自动带出坐标与城区；学生端据此按距离找活、打卡校验定位。
- **任务管理 / 处理报名**：查看学生学校、信用分、认证状态，录用（冻结任务款）/ 不录用。
- **订单验收**：查看打卡照片、**打卡定位距离与异常标记**、成果附件；验收通过（9:1 分账）/ 驳回整改 / 发起申诉。
- **账户与账单**：余额、已结算账单、**演示充值**。

### 运营后台（`admin.html`）
- **数据看板**：新增「隐私号联系次数」「带定位任务数」；纯 SVG 图表（订单状态环形图、近 7 日成交额、任务类目分布）。
- **资质审核**：学生学籍、企业执照待审列表，通过或驳回（原因通知到用户）。
- **任务审核**：通过上线或驳回。
- **争议仲裁**：查看托管金额、成果说明、附件、**打卡定位**、申诉理由，裁决退款或按约结算。
- **订单与风控**：全平台订单，新增「打卡定位」列（距离 + 异常标记）。

### 安全中心（`safety.html`）
- 一键拨打：110 / 12333 / 96110 / 12315 / 12348 / 平台客服。
- 兼职防坑清单：押金、培训贷、站外转账、刷单、证件保护、证据留存。
- 维权流程：平台申诉 → 劳动保障 → 报警 → 先行赔付。

## 核心业务规则（与案例报告一致）

1. **先审后发**：企业资质未通过不能发布任务；任务先进入 `待审核`，运营通过后才在任务大厅展示。
2. **资金托管**：企业录用学生时按单人报酬冻结任务款（从企业余额扣除），验收通过前学生不会拿到钱。
3. **9:1 分账**：验收通过后，学生实得 90%，平台服务费 10%，自动入账学生钱包。
4. **定位打卡**：任务有坐标时，打卡需在 5 公里内；超过 800 米记「定位异常」并通知运营；未授权定位可仅用照片留痕。
5. **履约留痕**：打卡照片 + 打卡坐标/距离 + 成果说明 + 成果附件，构成可追溯证据链。
6. **争议仲裁**：任意一方可对已交付订单发起申诉，订单进入 `争议中`，运营裁决后自动退款或结算并通知双方。
7. **隐私号联系**：报名后生成虚拟号，真实号码不直接暴露；联系方式仅用于本单沟通，平台记录联系时间。
8. **信用分与评价**：验收通过 +2（学生）、+1（企业）；企业评分在任务卡与详情展示。
9. **权限隔离**：学生只能报名与操作自己的订单；企业只能处理自己任务的报名与订单；运营才能审核与仲裁。

## 演示剧本（5 分钟）

1. 学生 `student` 登录：任务大厅切「地图找活」→ 点标记看详情 → 选「距离最近」排序；打开任务详情「联系企业」看隐私号。
2. 报名「茶颜悦色」→ 企业 `company` 处理报名并录用（余额冻结 22 元）。
3. 学生「我的订单」→ 打卡（允许定位后可见距任务地点距离）→ 上传现场照片 → 提交成果（附 1 张图）。
4. 企业「订单验收」→ 查看打卡定位与附件 → 验收通过；学生钱包到账 19.8 元并评价。
5. 学生 `student2` 登录：顶部认证横幅 → 提交学校学号 → 运营 `admin` 资质审核通过 → 再报名。
6. 运营后台：看板看图表与联系次数 → 争议仲裁里对种子订单裁决「退款给企业」→ 双方收到通知。
7. 任何页面右上角「安全」进入安全中心，演示一键拨打与防坑清单。

## 目录结构

```
website/
├── server.js              # 后端：HTTP 服务 + JSON API + 文件上传/读取（无依赖）
├── data/db.json           # 数据（含任务坐标、联系记录、通知），首次启动自动生成
├── data/uploads/          # 打卡照片与成果附件（运行时生成）
├── test_api.py            # 51 项端到端接口测试（会写入数据）
├── smoke_test.py          # 25 项只读冒烟测试（不动数据）
├── check_dom.py           # 静态检查：JS 引用的 DOM id 是否存在
├── test_report.txt        # 最近一次接口测试报告
├── smoke_report.txt       # 最近一次冒烟测试报告
└── public/
    ├── index.html         # 登录页
    ├── student.html       # 学生端
    ├── enterprise.html    # 企业端
    ├── admin.html         # 运营后台
    ├── safety.html        # 安全中心（电话与防坑）
    ├── css/style.css      # 统一样式（响应式，移动端可用）
    └── js/
        ├── common.js      # 请求封装、上传、通知、距离/地图辅助、认证横幅
        ├── student.js     # 含地图渲染与定位打卡
        ├── enterprise.js
        └── admin.js       # 含 SVG 图表与仲裁
```

| POST | `/api/orders/:id/review` | 双向评价 |
| POST | `/api/admin/orders/:id/arbitrate` | 运营仲裁（refund / pay） |

## 重置演示数据

停止服务，删除 `data/db.json` 与 `data/uploads/`，重新 `node server.js` 即可恢复初始演示数据。

## 说明与边界

- 这是**教学演示原型**：没有接入真实支付、实名认证、学籍核验、电子合同与发票；隐私号为模拟生成，未接运营商；地图为自绘示意图，导航跳转高德。
- 浏览器定位（GPS）在 `localhost` / `http://127.0.0.1` 下可用；部署到公网需 HTTPS 才能获取定位权限。
- 图片仅保存在本机 `data/uploads/`；真实上线需对象存储、图片鉴黄、访问签名与个人信息加密。
- 端口可用环境变量修改：`PORT=9000 node server.js`（Windows：`set PORT=9000 && node server.js`）。
